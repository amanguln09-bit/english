# Vercel-де іске қосу

Суреттегі `Unexpected token '<' ... is not valid JSON` қатесінің себебі: бұрын API бөлек Node серверінде болған. Vercel Next.js беттерін жариялап, сол бөлек серверді іске қоспағандықтан `/api/me` сұрауына HTML қайтқан.

Қазір `/api/[...path]` — Next.js серверлік маршруты. `/login` сервер деңгейінде `/dashboard` бетіне бағытталады; мұғалімге логин не құпиясөз қажет емес. Қолданбаға PostgreSQL керек: функциялардың уақытша дискісіне немесе бір процестің жадына сынып сессияларын сақтау дұрыс емес.

## Қажетті қадамдар

1. Тест үшін PostgreSQL базасын жасаңыз: мысалы, Vercel Storage/Marketplace арқылы PostgreSQL провайдерін қосыңыз немесе өзіңіздегі базаны пайдаланыңыз. Нақты оқушы деректері үшін мектептің деректерді сақтау орны мен рұқсаттарына қойылатын талаптарын алдын ала тексеріңіз.
2. Vercel → жоба → **Settings → Environment Variables** бөліміне `DATABASE_URL` қосыңыз. Мәні — провайдер берген PostgreSQL connection string. Production ортасын таңдаңыз; Preview жариялауларында қолдансаңыз, Preview үшін де баптаңыз. Мәнін чатқа жібермеңіз және GitHub-қа жазбаңыз. Провайдер талап еткен TLS тексеруін сақтаңыз. Serverless үшін провайдердің pooled connection URL нұсқасын қолданыңыз.
3. **Deployments → Redeploy** арқылы `main` тармағының ең соңғы коммитін қайта жариялаңыз. `vercel.json` ішіндегі `npm run vercel-build` командасы база бапталған жағдайда нұсқаланған миграцияларды орындап, содан кейін қолданбаны құрастырады. Миграция қатесі жариялауды тоқтатады.
4. `/dashboard` бетін ашып, ойын таңдаңыз және сессия бастаңыз. Екінші құрылғыдан PIN арқылы қосылып көріңіз.

`DATABASE_URL` болмаса, API 503 мәртебесімен түсінікті JSON қатесін қайтарады. Бұл жағдайда толық көпқатысушы ойын жұмыс істеді деп есептеуге болмайды. Ортаның құпия мәндерін көрмейтін осы чат Vercel жобаңызға базаны өзі қоса алмайды.

Қосымша: `PUBLIC_ORIGIN` — нақты сайттың HTTPS мекенжайы; QR-код үшін пайдалы. Cloudflare релесін қолдансаңыз, `CLOUDFLARE_RELAY_URL` және ортақ `RELAY_SECRET` жеке бапталады. Әкімші кіруі қосымша қызмет: мұғалімнің құпиясөзсіз жұмысына Supabase тіркелгісі қажет емес.

## Байланыс пен шектеулер

Vercel WebSocket серверін осы Next функциясының ішінде ұстамайды. Cloudflare релесі бапталмаған кезде интерфейс серверден күйді әр 3 секунд сайын сұрайды. Ұпай, уақыт шегі, рұқсат пен жауапты бір рет қабылдау серверде тексеріледі; таймер клиентте серверден келген уақыт бойынша көрсетіледі. Бұл тасымалдаудың кешігуі шамамен бір сұрау аралығы мен желі уақытына тең болуы мүмкін. Қажет болса, бөлек Cloudflare релесін баптаңыз.

Әр HTTP сұрауы дерекқордан соңғы сессия күйін оқиды. PostgreSQL advisory transaction lock тәуелсіз функциялар арасындағы өзгерістерді реттейді. Құлыпқа арналған connection pool мен деректер connection pool бөлек: күтіп тұрған сұраулар белсенді сұраудың дерекқор қосылымдарын тауыспайды. Бұл шағын сыныпқа арналған бастапқы шешім; үлкен жүктемеде әр сессияға бөлек құлыптар мен арнайы күй қызметін жобалау керек. Бір базаға custom Node сервері мен Vercel режимін бір уақытта жазушы ретінде қоспаңыз.

## Жергілікті тексеру

```bash
npm run vercel-build
npm run start:vercel
# Басқа терминалда:
E2E_TRANSPORT=polling npm run test:e2e
# Екі бөлек Next процесін бір PostgreSQL базасымен тексеру:
npx next start -p 3100
# Тағы бір терминалда:
npm run test:serverless
```

Vercel-дегі нақты жариялауды жергілікті тексерумен шатастырмаңыз. Бұл ортадан скриншоттағы сайтқа тікелей сұрауды желілік прокси 403 жауабымен бұғаттады; Vercel аккаунтына жариялау рұқсаты да берілмеген. Сондықтан сыртқы URL жұмыс істейтіні туралы тұжырым жасалмайды.
